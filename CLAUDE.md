- Background info about this workspace:
  This is the source code for a GitHub website built with Quarto
  for an Ohio State University (College of Food, Agricultural and Environmental Sciences)
  course "Practical Computing Skills for Omics Data",
  which focuses on teaching fundamental computing skills and reproducibility.
  Specific topics include the Unix Shell, Markdown, VS Code,
  the Ohio Supercomputer Center, shell scripts, Slurm batch jobs,
  Apptainer containers, R, Quarto, running Nextflow/nf-core pipelines,
  version control with Git and GitHub, code and research project documentation.
  Most students are grad students but the course can be taken by undergraduates
  as well. It has no prerequisites. 

- Theming for the website pages are defined in `styles.css` and `theme_web.scss`
- Theming for Quarto slides are defined in `slides.css` and `theme_slides.scss`
- Website settings are in `_quarto.yml`

- Do's and don'ts:
  - Don't open separately rendered HTML files that you ask me to check.
    I will always have a preview server running.
