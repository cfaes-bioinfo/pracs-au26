### GTF

9. For a gene of interest,
   you may wonder how many exons and other annotated features it has.
   GTF files have an implicit hierarchical structure,
   where e.g. each exon row contains a reference to the gene that the exon is a
   part of (i.e., its "parent") in the final column.
   With that in mind: for gene `LOC120427725`, print a count table of its feature types.
   _(You can assume that this gene's name does not occur in any lines_
   _describing features that are not part of the gene.)_

10. **_Bonus_**: Produce a 3-column table with the sequence name, start position,
    and end position of each _distinct_ start codon in the GTF file.
    Store that table in a file `start_codons.tsv`.
    _(You can assume that the string `start_codon` occurs only in the third column,_
    _so that all lines with that string contain start codon features.)_

11. **_Bonus_**: In this genome, which sequence (chromosome/scaffold/contig)
    appears to be the largest one?

    <details><summary>_Click here for a hint_</summary>
    This information is not directly contained in this GTF file,
    but if you are able find the highest number in the (start or) end coordinate
    column, and check which sequence that is on, you should get the correct answer.
    
    To do this, you need to first `cut` the relevant columns, and then `sort`
    specifically by the coordinate column (using the `-k` option).
    </details>
    
12. **_Bonus_**: Count the number of small nuclear RNAs (`snRNA`) in the annotation.
    You'll want a "gene"-level count
    (i.e. a count of the number of `gene` features annotated as `snRNA`),
    but because the word "snRNA" also occurs for other features,
    the search pattern `snRNA` would not work.
    An initial `grep` search would help to find a good final search pattern ---
    to spare you that trouble, it should be: `gene_biotype "snRNA"`.
    But this poses another challenge: the pattern contains double quotes (`"`),
    which we've been using to indicate where the search pattern begins and ends.

    <details><summary>_Click here for a hint_</summary>
    Use single quotes (`'`) instead of double quotes around the entire pattern.
    </details>
