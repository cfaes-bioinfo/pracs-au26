#### Exploding file names? _(Click to expand)_

When a file goes through multiple rounds of processing,
and you want to reflect all that in its name
(e.g., see the example above where `filter-by-mq30` may reflect one round of 
processing, and `sorted` another),
file names can get rather long.

In some cases, an alternative is to use different,
informatively named _folders_ for different rounds of processing,
while keeping the file names themselves stable and short,
e.g. just sample ID + file type (`mmus001.bam`).
:::
