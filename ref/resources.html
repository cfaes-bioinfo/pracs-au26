1 Introduction

This page lists further resources for learning about the topics covered in this course, and for learning more about related topics. Required readings and optional self-study resources from the pages for each week are also repeated here, so that you can find them all in one place.

2 Reproducibility

General

  • Good enough practices in scientific computing (Wilson et al. 2017, PLoS Computational Biology)
  • Reproducible Research: A Retrospective (Peng & Hicks 2021, Annu Rev Public Health)
  • Ten Simple Rules for Reproducible Computational Research (Sandve et al. 2013, PLoS Computational Biology)
  • The Turing Way – A community handbook on reproducible, collaborative data science.
  • Openness and Computational Reproducibility in Plant Pathology: Where We Stand and a Way Forward (Sparks et al. 2023, Phytopathology)
  • Open access and reproducibility in plant pathology research: Guidelines and best practices (Grünwald et al. 2024, Phytopathology)
  • The five pillars of computational reproducibility: bioinformatics and beyond (Ziemann et al. 2023, Briefings in Bioinformatics)
  • Five selfish reasons to work reproducibly (Markowetz 2015, Genome Biology)
  • A quick guide to organizing computational biology projects (Noble 2009, PLoS Computational Biology)

Data management and documentation

  • The FAIR Guiding Principles for scientific data management and stewardship (Wilkinson et al. 2016, Scientific Data)
  • What’s in a README? (Dryad blog), and a README template for datasets (Cornell University)
  • Project structure (slides by Danielle Navarro)

  • Nice collections of one-liners, mostly for bioinformatics

    • By Stephen Turner

    • By Amy Williams

Books

  • Linux Command Line and Shell Scripting Bible (Christine Bresnahan, 2015)

Further reading

  • Ten simple rules for getting started with command-line bioinformatics (Brandies & Hogg 2021, PLoS Computational Biology)
  • Five reasons why researchers should learn to love the command line (Perkel 2021, Nature)

5 Git

Online guides and tutorials – general

  • An overview of Git tutorials
  • Happy Git and GitHub for the useR Somewhat R-centric, but a very accessible introduction to Git.
  • Git best practices by Seth Robertson
  • Atlassian Git tutorials
  • A quick GitHub overview of some Git and GitHub functionality including branching and Pull Requests

Online guides and tutorials – interactive practice

  • Git-it – a small application to learn and practice Git and GitHub basics.
  • Learn Git branching
  • GitHub Skills – short interactive courses on using GitHub, which take place in a GitHub repository.

Further reading

  • A Quick Introduction to Version Control with Git and GitHub (Blischak et al. 2016, PLoS Computational Biology)
  • Not just for programmers: How GitHub can accelerate collaborative and reproducible research in ecology and evolution (Braga et al. 2023, Methods in Ecology and Evolution)
  • Excuse me, do you have a moment to talk about version control? (Bryan 2017, PeerJ)
  • Ten Simple Rules for Taking Advantage of Git and GitHub (Perez-Riverol et al. 2016, PLoS Comutational Biology)
