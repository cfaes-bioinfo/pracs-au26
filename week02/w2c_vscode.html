1 What is VS Code?

As a brief intermezzo, let’s take a look at VS Code, the fancy text editor you’ll use throughout the course to write code and documentation. Its full name is Visual Studio Code, while the version you can use in your browser at OSC is called “Code Server”.

To emphasize the additional functionality relative to basic text editors like Notepad and TextEdit, editors like VS Code are also referred to as IDEs: Integrated Development Environments. The RStudio program is another good example of an IDE. Just like RStudio is an IDE for R, VS Code will be our IDE for the Unix shell and Markdown1.

3 The VS Code user interface

3.1 The Primary Side Bar (wide)

The Primary Side Bar (wide side bar) shows a file explorer by default, where you can see files, create new folders and files, and so on.

If you’re in the correct location, you should see just two entries in the file explorer: the week02 and week03 folders you created in the previous session. If that’s not what you see, the box below will tell you how you can switch to your personal folder.

(Your OSC username should be printed above that, not because it knows who you are, but because that’s the name of the folder you are in.)

3.2 The Activity Bar (narrow)

The Activity Bar (narrow side bar) on the far left has, from top to bottom:

  • A (“hamburger menu”), with menu items like File — the kind you often find in a program’s top bar.

  • Icons such as to switch what the wide Side Bar shows: we’ll talk about those in a later session.

  • A circled user icon that we’ll also ignore for now.

  • A (cog wheel icon) at the bottom, with access to:

    • Settings, where you can configure VS Code.
    • “Command Palette”, a search bar to find and run all VS Code functionality.

TipA folder as a starting point

VS Code takes a specific folder as a starting point in all parts of the program, including its file explorer and the Unix shell in its terminal. You selected this folder when you started your VS Code session at OSC.

Generally speaking, if you’re not in the folder you want to work in, you should switch to the correct folder before continuing. For information on how to switch to a different folder, see the box below.

NoteSwitching folders (Click to expand)

If there was a problem with the Working Directory you selected when starting your VS Code session, you may have ended up in your Home dir instead (recall that this is /users/<project>/<user>). You can confirm this by looking at your browser’s address bar, which has the folder path at the end:

If you instead see a path that starts with /users/, then you can switch to your personal folder from within VS Code:

  1. Click > File > Open Folder.
  2. Enter the correct path /fs/ess/PAS3493/people/<user>, replacing <user> with your OSC username.
  3. This will cause the program to reload.

3.3 Terminal (with a Unix shell)

Open a terminal by clicking > Terminal > New Terminal. A whole new panel will appear at the bottom of the window, with a Terminal tab. We’ll start using this in the next lecture.

The VS Code window with a terminal open at the bottom. The editor pane above shows the Get Started document.

TipResizing panes

You can resize panes by hovering your cursor over the borders between them and then dragging. Try doing this with the border between the Primary Side Bar and the editor pane, and that between the panel with the terminal and the editor pane.

3.4 Editor pane and “Get Started” document

The main part of VS Code is the editor pane. Here, you can open scripts and other types of text files, images, and so on. Like in a web browser and other modern editors, you can have multiple tabs open.

Whenever you open VS Code, an editor tab with a “Get Started” document is automatically opened. This provides some help and shortcuts to recently opened files and folders.

Let’s create a new file and save it as a Markdown file, for the next lecture:

  1. Open a new file by clicking > File > New Text File2.

  2. The file will be called “Untitled-1” and will contain some “ghost text” you can ignore:

  1. Before typing anything, save the file: press Ctrl/⌘+S (i.e., the common “Save” shortcut you are likely familiar with) and save it within your week02 dir as 2d_markdown.md.
  1. Because you saved it with the .md extension, VS Code will recognize it as a Markdown file, hence the Markdown icon (downward arrow) in the tab.
