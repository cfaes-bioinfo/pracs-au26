High-performance computing

What is a supercomputer?

What is a supercomputer?

  • Many computers connected by a high-speed network.
  • Can be accessed remotely by its users.

What does it provide?

High-Performance Computing (HPC) resources — which have two main aspects:

  • Compute: computing power to run your data processing and analysis.
  • Storage: space for storage of your data and results.

Terminology

Supercomputers are also known as “compute clusters” or simply “clusters”.

Why use a supercomputer?

Can you think of any reasons to use a supercomputer instead of your own computer?
  • Your analyses take a long time to run, need large numbers of processors, or a large amount of memory.
  • You need to run an analysis many times.
  • You need to store a lot of data.
  • Your analyses require Linux-only software, but you have Windows.
  • Your analyses require specialized hardware, such as GPUs.

When working with omics data, many of these reasons often apply. This can make it hard or impossible to run all your analyses on your computer, and supercomputers provide a solution.

The Ohio Supercomputer Center (OSC)

What is OSC?

  • The Ohio Supercomputer Center (OSC) is a supercomputer facility provided by the state of Ohio.
  • OSC has three supercomputers, lots of storage space, and excellent infrastructure to access these resources.

Cardinal, one of OSC’s supercomputers.

OSC Projects

Access to and usage of OSC goes through OSC “Projects”.

Scope of a project

A project can be tied to a lab or research project, or be educational like this course’s project.

The OSC Project for this course is PAS3493.

Projects are the billing units

OSC charges for “compute hours” and storage space, and does so at the level of a project (not individual users).

From a user perspective

You can be a member of any number of projects.

  • Specify the appropriate project when requesting compute.
  • Use the corresponding locations when storing files.

The structure of a supercomputer center

Terminology

Node
A single computer that is a part of a supercomputer.

Supercomputer / Cluster
A collection of connected computers/nodes.

Supercomputer Center
A facility like OSC with one or more supercomputers. OSC has three: “Ascend”, “Cardinal”, and “Pitzer”.

Terminology

Or, shown in another way:

Supercomputer Center

Supercomputer

Node

Supercomputer components

Main parts of a supercomputer:

  • Login nodes
    The handful of computers everyone shares after logging in.
  • Compute nodes (for compute)
    The many computers you can reserve to run your analyses.
  • File system (for storage)
    Where files are stored — one system shared across all clusters.

Login versus compute nodes

Login nodes

An initial landing spot when you log in to a supercomputer:

  • There are only a handful of them on each supercomputer.
  • They are shared among everyone, and cannot be reserved for exclusive usage.

Login nodes are meant only for light tasks such as organizing files and creating scripts for compute jobs, and not for serious computing.

Compute nodes

This is where serious computation, such as data analysis, takes place:

  • To access compute nodes, you need to request a “compute job”.

  • A job scheduler program then assigns the requested resources — for example, access to a specific compute node for two hours.

“guest” is inside “home”. In other words, “guest” is a subfolder of “home”, and “home” is the parent folder of “guest”.

File system – first some background

In file paths, what does the / represent?

  1.   A leading / indicates the current user’s home folder, and any other /s separate folders in the path.

  2.   A / separates a file’s name from its extension, similar to how a period is used.

  3.   A leading / indicates the root folder, and any other /s separate folders in the path.

  4.   A / marks the boundary between a drive letter and the rest of the path, as in Windows.
